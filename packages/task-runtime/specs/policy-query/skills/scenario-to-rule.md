# 从情景描述到监管表述

用户描述的是**发生了什么事**,制度写的是**什么行为受什么约束**。两者用词往往完全不重合,
直接拿用户原话去检索命中率很低。

## 先拆解行为要素

把情景拆成四个要素,再用监管词汇重组:

- **主体** —— 谁做的?(从业人员 / 投资顾问 / 上市公司 / 保荐机构 / 控股股东……)
- **对象** —— 对谁做的?(客户 / 投资者 / 关联方 / 监管机构……)
- **行为** —— 做了什么?(招揽 / 荐股 / 代客理财 / 信息披露 / 关联交易……)
- **场合** —— 在什么条件下?(展业期间 / 持续督导期 / 重大事项发生后……)

## 口语 ↔ 术语对照

| 用户会这么说 | 制度里写作 |
|---|---|
| 「这个股票见底了/到顶了」 | 提供具体股票的买卖建议、证券投资顾问业务 |
| 「拉人开户」「发二维码」 | 招揽客户、开立账户、展业行为规范 |
| 「帮客户操作」 | 代客理财、全权委托 |
| 「私下收钱」 | 从业人员违规收受财物、利益输送 |
| 「消息还没公告就说了」 | 未公开信息、信息披露公平性、内幕信息 |
| 「查账」「来人查」 | 现场检查、非现场监管、自律监管措施 |

## 检索策略

1. 先用改写后的监管表述检索一次
2. 命中不理想就**换角度**,不要重复同一组词 —— 换主体、换行为、换上位概念
3. 判断类问题往往要检索两次以上:一次找行为规范,一次找罚则或监管措施
4. 仍然检不到,如实说「在可检索范围内未找到对应规定」,不要拿相近但不对题的条款硬凑

## 不要做的事

不要因为检索不到就降低标准去引用一条「看起来相关」的条款。
用户拿到一条不对题的依据,比拿到「没找到」更容易做出错误决定。
