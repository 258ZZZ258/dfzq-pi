# 数据源契约

| 数据源 | 主要用途 | 生产接入状态 | 关键要求 |
|---|---|---|---|
| DS-01 审计项目 | 报告类型、期间、流程状态 | 已具备 | 以项目 ID 锁定范围 |
| DS-02 营业部基础库 | 名称、地址、面积、沿革 | 待接口 | 按审计截止日快照 |
| DS-03 审计发现与整改 | 问题、分类、数量、整改状态 | 目前导出 | 列表取 ID，详情取全文 |
| DS-04 经营数据 Excel | 收入、利润、客户、排名 | 已具备 | 保存文件哈希及单元格位置 |
| DS-05 OA 发文 | 任免、主持工作、机构变更 | 待接口 | 保存文号、发文主体和日期 |
| DS-06 人事与经纪人系统 | 人员、资格、任职期间 | 待接口 | 使用审计截止日快照 |
| DS-07 反洗钱系统 | 风险等级、可疑交易、审查 | 待接口 | 六个领域逐项取状态 |
| DS-08 风险事项确认 | 投诉、诉讼、处罚、损失 | 人工确认 | 缺失不能推断为无 |
| DS-09 绩效与问责 | 绩效等级、问责 | 人工确认 | 保留年度和文件依据 |
| DS-10 营业部材料 | 培训、租赁、整改附件 | 人工上传 | 保存文件 ID、哈希和页行 |
| DS-11 制度知识库 | 制度依据 | 已具备 | 记录制度版本和条款 |
| DS-12 监管函/处罚 | 监管事件交叉核验 | 人工交叉核验 | 记录检索条件和截止日 |

生产可用性与字段设计完整性必须分开评价：字段被定义并不代表接口已经接通。
