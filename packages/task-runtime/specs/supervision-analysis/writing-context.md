任务的 `analysisStart` 与 `analysisEnd` 是统一的分析期间，含起止日；资料、问题、整改和问责均以此期间为限。
不另设整改截至日期。汇总整改进展时使用分析期间内的已确认记录，不写入期间外进展。

固定生成《监督信息汇总分析报告》，完整保留规定的章节、问题归类、整改情况、问责和日常监督内容。
任务没有来源类型范围、来源部门范围、报告口径或关注重点勾选配置。

`task.analysisDescription` 是选填的“分析说明”，用于提供分析背景和特别关注事项。
有值时，在相应固定章节中适当展开已有事实；未填时按固定框架正常撰写。
分析说明不是事实证据，不得当作资料引用；不得据此虚构事项、改变分析期间、重算统计或省略其他固定模块。
