# 报告规则

## 通用

- 数据准备区间与正式审计期间分开记录。
- 机构名称使用审计截止日口径；机构变更另行描述。
- 经营指标保持模板行序，负数不得漏负号。
- 排名档位：前 20% 上游，20%—40% 中上游，40%—60% 中游，60%—80% 中下游，后 20% 下游。
- 同类问题可以分组，但每个 finding ID 必须可回溯，不能合并掉独立事实。
- “个别”仅用于问题数不超过 2；“部分”用于问题数大于 2。
- 固定模板采用规则生成并锁定，不允许模型改写标题、引言、审计依据、章节名、问题事实、制度依据、结论、建议、落款和日期。
- 模型仅可归纳经营情况分析段，且只能修改 `regular-operating-analysis` 或 `turnover-operating-analysis`。
- 中文正文统一使用全角标点；提交前自动纠正半角逗号、冒号、分号、问号、感叹号和括号，并消除“经审计，经审计”等机械重复。
- 地址、面积、人数等关键字段缺失或为模拟/零值时阻断报告，不得把占位值写入正文。
- 排名表仅保留同时具有排名分子、排名分母的指标；无排名的“其他收入”“业务管理费”等指标不得为凑表格而输出。
- DOCX所有可见格式从报告类型对应的原始模板继承，不由模型控制，也不在代码中重新猜测字体、字号和间距。

## 常规报告

- 包含审计项目基本情况、营业部基本情况、主要问题、结论与建议。
- 风险事项只有在各域均为 `VERIFIED_NONE` 或有相反事件明细时才可下结论。

## 离任报告

- 人员 ID、任期起止、文号、发文主体和主持工作/代职信息必须一致。
- 历史问题按任职期间过滤，但重大问题和未整改问题不得因整改状态被删除。
- 绩效、廉洁从业、投诉、问责和结论均为人工复核项。

## 反洗钱报告

- 内控制度、客户身份识别、风险等级、可疑交易、资料保存、培训宣传六个领域必须全部取得状态。
- 可疑交易同时列交易类型、数量和报送状态。
- 只有六个领域均核查完成且人工确认后，才可采用“未发现问题”版本。
